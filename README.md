# accessible-site

Демонстрационный репозиторий с доступным модальным компонентом и улучшенной CSS/SCSS структурой.

Содержит:
- index.html — пример страницы
- styles.css — готовые стили
- modal.js — доступная реализация модального с focus-trap и клавиатурной навигацией
- styles.scss — SCSS-версия
- ACCESSIBILITY_CHECKLIST.md — чеклист для тестирования по WCAG

Сайт публикуется через GitHub Pages на ветке gh-pages.
