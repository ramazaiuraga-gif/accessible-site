# Чеклист доступности (WCAG AA) — быстрая проверка

1. Семантика и язык
   - Страница имеет корректный атрибут lang (например, <html lang="ru">).
   - Использованы семантические элементы (header, main, nav, footer, h1..h3).

2. Клавиатурная навигация
   - Все интерактивные элементы доступны и видимы при Tab.
   - Модальное окно открывается и закрывается клавишей Escape.
   - Фокус не теряется — возвращается на элемент, открывший модал.

3. Видимость фокуса
   - :focus-visible стили применяются (контрастный outline).

4. Формы
   - Каждое поле имеет связанный <label for="...">.
   - Ошибки формы объявлены и доступны (aria-live / aria-invalid) — при расширении добавить.

5. Контраст
   - Контраст текста против фона — минимум 4.5:1 для обычного текста (проверить инструментариями, например axe, Lighthouse).

6. Объявления для SR
   - Модальное окно содержит role="dialog" и aria-modal="true".
   - При открытии/закрытии устанавливается aria-hidden на фоновые элементы или используется inert.

7. Управление фокусом
   - Реализован фокус‑трап внутри модала.
   - Переключение фокуса на первый фокусируемый элемент после открытия.

8. Доступность анимаций
   - При prefers-reduced-motion анимации/транзишны отключены.

9. Тестирование
   - Прогнать axe / Lighthouse / WAVE.
   - Проверить в NVDA/VoiceOver (основные сценарии: открыть модал, заполнить форму, закрыть).
   - Проверить на мобильных устройствах: масштабирование, экранная клавиатура, touch targets.

10. Дополнительно (рекомендации)
    - Подумать о live-region для уведомлений.
    - Добавить aria-describedby для полей с подсказками.
    - Поддержать inert polyfill при необходимости.
